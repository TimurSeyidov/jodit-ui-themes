Themes for the [Jodit](https://xdsoft.net/jodit/) editor: the editor itself, the free file browser and the Jodit PRO finder. Each theme is a plain stylesheet loaded after the Jodit styles; no Jodit rebuild is needed.

## Files

Every theme lives in `themes/<name>/`:

| File | Contents |
|---|---|
| `<name>.all.css` | everything: editor and both file browsers |
| `<name>.editor.css` | editor: toolbar, buttons, popups and menus, dialogs, form fields, status bar |
| `<name>.finder.css` | file browsers: the free Jodit file browser and the Jodit PRO finder |
| `_theme.less` | palette and theme-specific rules (themes built on the shared base) |
| `README.md` | theme description, shown in the theme list above |
| `screenshots/` | `main.png`, `editor.png`, `finder.png`, `finder-pro.png` from `npm run screenshots` |

Each stylesheet comes as `.css`, `.min.css` and the `.less` source. The finder part relies on the editor part for buttons, inputs and menus inside the file browser window, so load either `all` or both `editor` and `finder`.

## Creating a theme

Most themes are built on the shared base in `themes/_base/`: `editor.less` and `finder.less` style everything from `--ui-*` custom properties, and `tokens.less` holds their defaults. A new theme only needs a palette:

1. Copy a theme folder close to the look you want (for example `themes/syncfusion/`) and rename the folder and the files.
2. Replace the old name with the new one inside `<name>.editor.less`, `<name>.finder.less` and `<name>.all.less`.
3. Set the colours, radii and fonts in `.theme-tokens()` in `_theme.less`; the available tokens and their defaults are listed in `themes/_base/tokens.less`. Rules that the tokens cannot express go to `.theme-editor()` and `.theme-finder()`.
4. Describe the theme in `README.md`, then run `npm run build` and `npm run screenshots`.

Names starting with `_` are partials: they are imported by the themes and are not compiled on their own. `office2010` and `windows10` are standalone stylesheets that do not use the base.

## Usage

### From a CDN

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/jodit@4/es2021/jodit.min.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/jodit-ui-themes@0/themes/office2010/office2010.all.min.css" />
<script src="https://cdn.jsdelivr.net/npm/jodit@4/es2021/jodit.min.js"></script>
<script>
	Jodit.make('#editor', { theme: 'office2010' });
</script>
```

Every file of the package is on [jsDelivr](https://www.jsdelivr.com/package/npm/jodit-ui-themes) and [unpkg](https://unpkg.com/browse/jodit-ui-themes/): `https://cdn.jsdelivr.net/npm/jodit-ui-themes@<version>/themes/<name>/<name>.<part>.min.css` or `https://unpkg.com/jodit-ui-themes@<version>/themes/<name>/<name>.<part>.min.css`. Pin an exact version (`@0.1.0`) in production; `@0` follows the latest compatible release. Each theme above has a ready-to-copy `<link>`.

### From npm

```
npm install jodit-ui-themes
```

```js
import 'jodit/es2021/jodit.min.css';
import 'jodit-ui-themes/themes/office2010/office2010.all.min.css';
import { Jodit } from 'jodit';

Jodit.make('#editor', { theme: 'office2010' });
```

The package also ships the `.less` sources, so a theme can be compiled into your own build.

### Notes

- Load the theme **after** the Jodit stylesheets.
- The same stylesheet works with Jodit and Jodit PRO.
- Switching `theme` on a live editor leaves the previous theme class in place; recreate the editor instead.
- The Jodit PRO finder keeps the last used theme in `localStorage` and prefers it over the `theme` option. Clear that value if the theme does not apply.
- If the editor lives in a shadow root, put the theme `<link>` inside the shadow root.

## Compatibility

Checked with Jodit 4.17.1 and Jodit PRO 4.15.13. Themes style Jodit's internal class names, which may change between Jodit versions.

## Building

```
npm install
npm run build   # compile every themes/*/*.less into .css and .min.css
npm run watch   # rebuild on every .less change
npm run screenshots              # screenshots of every theme + README theme list
npm run screenshots -- office2010   # only the given themes
```

`npm run screenshots` opens Jodit and Jodit PRO in a headless browser, saves `themes/<name>/screenshots/{main,editor,finder,finder-pro}.png` and rewrites the list between the `themes` markers in this README: for every theme its name, the description from `themes/<name>/README.md` and the screenshots. The file browsers use a built-in fake connector with fixed files, so the pictures are the same on every run. It uses the Playwright Chromium (`npx playwright install chromium`) or, when that is missing, the installed Google Chrome. Fonts come from the operating system, so take screenshots on the same machine to keep them comparable.

The generated `.css` and `.min.css` files are committed together with their `.less` sources, so a theme can be used straight from the repository. After changing a `.less` file, run `npm run build` and commit the result: CI rebuilds the themes and fails if the committed CSS is out of date.

## Releasing

```
npm version patch   # or minor / major: bumps package.json, updates the CDN links in README.md, commits and tags
git push --follow-tags
```

Pushing the `v*` tag runs the Publish workflow: it checks that the tag matches `package.json`, rebuilds the themes, verifies the committed CSS and publishes the package to npm through [trusted publishing](https://docs.npmjs.com/trusted-publishers/) (no token, provenance attached). Within minutes the new version is on jsDelivr and unpkg.
