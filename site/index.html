jodit-ui-themes

CSS themes for the Jodit editor, its file browser and the Jodit PRO finder.

GitHub npm

  • The file browsers show the files of the public Jodit demo connector. Uploads, renames, moves and deletes are answered by the page itself and are not saved.
  • Images uploaded into the text are embedded as data URLs.
  • Jodit PRO shows a trial note until a license key is set for this domain.
